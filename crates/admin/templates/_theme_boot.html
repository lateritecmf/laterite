{# Theme boot, inline and blocking on purpose. It runs before first paint so a dark-mode operator never sees a white flash, which rules out the deferred script: by the time that runs the page is already on screen. It also owns the "auto" mode's promise. Auto means follow the system, and the system moves: an admin left open through dusk would otherwise stay light until someone reloaded it. An explicit light or dark is the operator overriding the system and stays put. `latApplyMode` is defined here rather than in laterite.js so every screen has it, including the pre-auth ones that load no script. #}
