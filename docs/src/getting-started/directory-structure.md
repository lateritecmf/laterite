# Directory Structure

`lat new` generates an application in this layout.

```text
acme/
├── Cargo.toml
├── README.md
├── .gitignore
├── config/
│   ├── default.toml     # committed defaults
│   └── local.toml       # git-ignored; the database URL
├── plugins/
│   └── plugins.toml     # the installed plugins
├── plugins-manifest/    # generated by `lat plugin sync`
├── src/
│   └── main.rs
└── storage/             # runtime data; git-ignored
```

Path | Holds
--- | ---
`Cargo.toml` | The application crate and the workspace its plugins join.
`config/` | The layered configuration. See [Application and Server](../configuration/application.md).
`plugins/` | Installed plugin crates and the list that names them, the project's own among them: its screens, tables, permissions and settings live in a plugin. See [Writing a Plugin](../plugins/writing-a-plugin.md) and [Installing Plugins](../plugins/installing.md).
`plugins-manifest/` | The generated crate that links the listed plugins. Never edited by hand.
`src/main.rs` | The entry point.
`storage/` | Files the application keeps while it runs. `backend.storage` moves it.

## Read `main.rs`

```toml
[dependencies]
lateritecmf = { version = "0.12", features = ["postgres"] }
laterite-core = "0.12"
plugins-manifest = { path = "plugins-manifest" }
```

```rust
use lateritecmf::prelude::*;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    Bootstrap::new("config")
        // Every plugin under plugins/, as listed in plugins/plugins.toml.
        .modules(plugins_manifest::all())
        // .extend(|router, ctx| router.merge(my_api(ctx.db())))
        .run()
        .await
}
```

Call | Description
--- | ---
`Bootstrap::new("config")` | The configuration directory, relative to the working directory.
`.modules(..)` | The installed plugins.
`.extend(..)` | Merges the application's own routes onto the admin router.

## Add the project's own plugin

```
lat make:plugin acme.blog --admin --path plugins
lat plugin add plugins/blog-plugin
lat make:resource article --field title:text,body:text --path plugins/blog-plugin
lat make:migration add_article_summary --path plugins/blog-plugin
```

Command | Makes
--- | ---
`lat make:plugin <vendor.name>` | A plugin crate under `plugins/`, with its module and an empty migration set.
`lat plugin add <path>` | The entry in `plugins/plugins.toml` and the generated manifest.
`lat make:resource <name>` | A list and form screen with its table's migration, in the plugin at `--path`.
`lat make:migration <description>` | A migration file listed in the plugin's set.

## Read the configuration

```toml
# config/default.toml
[app]
name = "Acme Blog"
env_prefix = "LAT"
# url = "https://acme.example"

[server]
listen = "127.0.0.1:8080"

[backend]
timezone = "UTC"
secure_cookie = false
# path = "/admin"
```

```toml
# config/local.toml
[database]
url = "postgres://localhost/acme"
```

Every key is in [Configuration](../configuration/application.md).
