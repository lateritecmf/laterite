# Directory Structure

`lat new` generates an application in this layout.

```text
acme/
├── Cargo.toml
├── README.md
├── .gitignore
├── config/
│   ├── default.toml     # committed defaults
│   └── local.toml       # git-ignored; the database URL
├── plugins/
│   └── plugins.toml     # the installed plugins
├── plugins-manifest/    # generated by `lat plugin sync`
├── src/
│   ├── main.rs
│   └── migrations/      # the application's module and its migrations
└── storage/             # runtime data; git-ignored
```

Path | Holds
--- | ---
`Cargo.toml` | The application crate and the workspace its plugins join.
`config/` | The layered configuration. See [Application and Server](../configuration/application.md).
`plugins/` | Installed plugin crates and the list that names them. See [Installing Plugins](../plugins/installing.md).
`plugins-manifest/` | The generated crate that links the listed plugins. Never edited by hand.
`src/main.rs` | The entry point.
`src/migrations/` | The application's module and its migrations. See [Migrations](../database/migrations.md).
`storage/` | Files the application keeps while it runs. `backend.storage` moves it.

## Read `main.rs`

```toml
[dependencies]
lateritecmf = { version = "0.9", features = ["postgres"] }
laterite-core = "0.9"
plugins-manifest = { path = "plugins-manifest" }
```

```rust
use lateritecmf::prelude::*;

mod migrations;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    Bootstrap::new("config")
        // Every plugin under plugins/, as listed in plugins/plugins.toml.
        .modules(plugins_manifest::all())
        .module(migrations::AppModule)
        // .extend(|router, ctx| router.merge(my_api(ctx.db())))
        .run()
        .await
}
```

Call | Description
--- | ---
`Bootstrap::new("config")` | The configuration directory, relative to the working directory.
`.modules(..)` | The installed plugins.
`.module(..)` | The application's own module.
`.extend(..)` | Merges the application's own routes onto the admin router.

## Read the module

`src/migrations/mod.rs` defines the application's module:

```rust
use lateritecmf::prelude::*;

migration_set! {
    module_id: "acme",
}

pub struct AppModule;

impl Module for AppModule {
    fn id(&self) -> ModuleId {
        ModuleId::new(MODULE_ID)
    }
    fn migrations(&self) -> MigrationSet {
        migrations()
    }
}
```

`lat make:migration <description>` adds a file to the directory and lists it in
the `migration_set!` block. The methods a module may add are in
[Writing a Plugin](../plugins/writing-a-plugin.md).

## Read the configuration

```toml
# config/default.toml
[app]
name = "Acme Blog"
env_prefix = "LAT"
# url = "https://acme.example"

[server]
listen = "127.0.0.1:8080"

[backend]
timezone = "UTC"
secure_cookie = false
# path = "/admin"
```

```toml
# config/local.toml
[database]
url = "postgres://localhost/acme"
```

Every key is in [Configuration](../configuration/application.md).
