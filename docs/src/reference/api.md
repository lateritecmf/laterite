# API Reference

The per-crate API documentation is generated by rustdoc from the source. Build
it locally with:

```bash
cargo doc --workspace --no-deps --open
```

Every public type, function, and trait carries doc comments, so the generated
reference is the authoritative description of each crate's surface. Once the
crates are published, the same documentation is available on
[docs.rs](https://docs.rs).
